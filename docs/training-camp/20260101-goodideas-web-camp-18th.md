你有沒有注意到，有一種等待，比任何困難都更消耗人。

不是等不到機會，而是一直在等「自己準備好」。

等學歷更好一點。等存款多一點。等手上的事情告一段落。
等到某個時間點，再來認真面對那件一直擱著的事。

但那個「對的時機」，從來沒有真正來過。

因為它不是一個時間點，它是你選擇面對的那一刻。

很多人說：「我還沒準備好。」
但真正願意改變的人，不是等到準備好才開始——
他們是在還沒準備好的時候，選擇跳進去。

這一跳，才是真正的開始。

寫程式這件事，不需要完美的起跑點。
它需要的是，你願意在迷霧裡還是選擇走下去的那份決心。

好想工作室 Web Camp，給的不是一條捷徑，
而是一個讓你真正體驗「開始改變」的環境。

如果你已經等夠久了，現在就是那個時機。

### 我們如何培訓工程師

我們的培訓沒有固定模式，目的是培養你「自學的思維與習慣」，並讓你對自己負責。

- 沒有固定的上課時間
- 沒有固定的講師
- 沒有固定的課程

「無固定模式」可能讓你感到疑惑，那麼你來這裡究竟要做什麼呢？

這裡不給你答案，但給你一個讓你真正改變的環境。

我們會提供循序漸進的任務，讓你在實際動手的過程中遭遇真實的痛點，而不是讓你讀完教學、點頭稱是，卻什麼都沒留下。這些任務的設計，是為了讓你知道「自己不知道什麼」，進而找到問題、研究問題、解決問題——這才是工程師真正需要的能力。

環境裡有不同背景的進駐者與學員，大家在開放的氛圍中交流、分享。你的迷惘不會被笑，你的問題會得到真誠的回應，偶爾還能獲得意料之外的啟發。

這樣的環境，會讓你開始改變看待學習這件事的方式——從「等人給答案」，轉變為「主動找答案」。

而你唯一需要做的事情，就是「付出時間，融入環境，並對自己的成長負責。」

### 常見 Q&A

- **Q: 好想工作室是一個什麼樣的地方？**
  可以看看 Howard 拍的影片: [開箱好想工作室!?好想工作室在幹嘛??](https://youtu.be/Dft5rHiFTis)
  如果還有疑惑，可以找 [Facebook 小編](https://www.facebook.com/GoodideasStudio)或 [IG 小編](https://www.instagram.com/explore/locations/1027627606/hao-xiang-gong-zuo-shi/)約時間來參觀看看。
- **Q：參加培訓需要學費或額外費用嗎？**
  台南好想工作室 Web Camp 培訓 6 個月期間內免費。
- **Q：培訓過程主要為自主學習研究？**
  是的。可以參考上述「我們如何培訓工程師」那一段。
- **Q：因為白天有工作，能否晚上或遠端參與培訓嗎？**
  不行，因為時間的投入是好想工作室希望學員付出的唯一要求。如果無法在工作室投入時間，建議先嘗試其他線上課程。
- **Q：每天在好想學習的時間，可以彈性調整嗎？(包含晚點來、特定時段固定請假)**
  以不影響學習效率為前提，可以彈性調整學習時間。不過我們認為養成「固定作息」是提升學習效率的重要因素。除此之外，在一般日常時間待在好想，才能把握住和伙伴們相處交流、成長的重要時間。
- **Q：參加過別的培訓班、補習班、職訓之後，可以再來報名嗎？**
  選擇學習資源的決定在於你自己，我們都歡迎有心想學的人。
- **Q：非相關背景或英文、數理邏輯不好，是否適合 training？**
  我們並不會因為這些條件來決定你是否適合 training。每個人皆有不同的現實考量，只有你自己能選擇未來要如何前行。
- **Q：招募需通過篩選機制？**
  對，因為好想工作室的資源有限，希望把資源給需要而適合的人。
- **Q：寄信後會收到回覆嗎？多久會收到呢？**
  不管你的申請結果如何都會收到回信，我們也不喜歡無聲卡。
  因為我們各自有正職工作，只能利用空閒時間審核信件，請稍等一段時間，最慢兩個月內會收到回覆，如果真的等不及了，也可以找 [Facebook](https://www.facebook.com/GoodideasStudio) 小編問看看。
